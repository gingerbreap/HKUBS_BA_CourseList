# What is a PWA

Key characteristics of a PWA include:

* Reliable — loads and displays instantly even on unstable networks or offline
* User experience — responds quickly, with smooth transitions and feedback to user actions
* Engagement — like a native app, it can be added to the home screen, receive offline notifications, and offer an immersive experience

A PWA is **progressive**. That idea works in two ways: first, the platform keeps evolving—standards such as Service Worker, Web App Manifest, and Device APIs improve every year; second, those standards are designed to be backward-compatible and low-impact, so developers can add new capabilities on top of an existing site and enhance the experience gradually.

## PWA characteristics

A PWA is still a Web App, but newer technologies give it some native-app traits. It combines strengths of both Web and native apps, with major gains in security, experience, and engagement. In short, a PWA is:

* **Progressive** — works across browsers because it is built with progressive enhancement
* **Connectivity independent** — with a Service Worker, it can work offline or on a poor network
* **App-like** — built on an App Shell model, so interaction feels closer to a native app
* **Always up to date** — stays current without manual version updates
* **Secure** — served over HTTPS to reduce snooping and tampering
* **Discoverable** — the manifest and Service Worker help search engines recognize it as an “app”
* **Engaging** — features such as offline push can bring users back
* **Installable** — users can add it to the home screen without an app store download
* **Linkable** — content can be shared with a URL; no install required first

These traits give Web Apps new life where native apps struggle. Native apps are closed by nature: their content is hard to index and hard to distribute. Want a recipe? You may first need the app’s name, then download it, then find the content—an awkward flow. Google has noted that the average number of apps a user installs per month is near zero, while a few top apps take most of people’s time, so distribution gets ever more expensive. By contrast, PWAs follow open standards, so browsers can support them quickly and developers can adopt them more easily.

|   |Installable|Linkable|Experience|Engagement|
|---|---|---|---|---|
|Traditional Web|No|Yes|Average|Low|
|Native App|Yes|No|Strong|Strong|
|PWA|Yes|Yes|Strong|Strong|
